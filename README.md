# i5 Adversary Hunt

I made this for my i5 space group (Dr. Gladys West Squadron). You join a room with a callsign, ready up, and everyone gets their own desk based on a Space Force career field. The desks are chained together, so nobody can solve it alone. You have to actually talk to your team and put the pieces together before the timer runs out.

I came up with the idea, designed all the puzzles and the Space Force theme, and set up the Firebase backend. Used Claude to help out with some of the code.

Built with HTML, CSS, JavaScript and Firebase, hosted on GitHub Pages.
